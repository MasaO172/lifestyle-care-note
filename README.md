# 生活習慣ケアノート v54 — GitHub Pages 公開用PWA

## 公開方法（最初の1回）
1. GitHubで新しいリポジトリを作成します。推奨名: `lifestyle-care-note`
2. このZIP内のファイルを、フォルダを作らずリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` で `Deploy from a branch` を選び、Branch=`main`、Folder=`/(root)` を指定して保存します。
5. 数分後に表示される `https://<GitHubユーザー名>.github.io/lifestyle-care-note/` を開きます。
6. iPhoneではSafariで開き、共有 →「ホーム画面に追加」でPWAとして使用できます。

## 今後の更新
利用者側でHTMLファイルを差し替える必要はありません。
同じGitHubリポジトリの `index.html`、`sw.js`、`manifest.webmanifest` 等を新しい版に置き換えるだけで、同じURLから最新版が配信されます。
この版ではPWA起動時にService Workerの更新確認を行い、新版が有効になった場合は自動的に再読み込みします。

## データ保存について
患者データはブラウザ/PWAの端末内ストレージに保存されます。GitHubには患者データを送信しません。
ただし、端末変更、Safariのサイトデータ削除、PWA削除などに備えて、アプリ内の「完全バックアップ(JSON)」を定期的に保存してください。

## 公開時の注意
GitHub PagesをPublic repositoryから公開する場合、HTML/JavaScriptなどのソースコードも公開されます。
本ツールのライセンスは `LICENSE.txt` およびアプリ内表記に従います。

## v54 変更

## v54 変更
- 外来のABSI表示に「結果の解釈」を追加。
- ABSIは同じBMI・身長に対して腹囲が相対的に大きいほど高くなる指標であることを表示。
- 高いABSIは腹部肥満・死亡リスクとの関連が報告されていることを表示。
- 年齢・性別で基準値が異なるため、raw ABSIに一律の正常／高値カットオフを設定せず、診断区分ではなく経時変化を見る参考値として表示。

## v54 変更
- ABSIが計算できる場合に、任意の年齢・性別入力欄を表示。
- 入力時はNHANES 1999–2004の年齢・性別別ABSI基準からz-scoreを算出。
- z-scoreを5群の相対区分で参考評価。
- 未入力時はv50のraw ABSI解釈文をそのまま表示。
- 85歳以上は原著の85歳以上群の基準値を使用。
- 米国NHANES基準であり、日本人の診断基準ではないことを明記。

## v54 変更
- ABSI結果表示に「ABSIとは」の短い説明を追加。
- ABSIは A Body Shape Index の略で、身長と体重（BMI）に対して腹囲がどの程度大きいかを見る体型指標であることを表示。
- 年齢・性別を入力してz-scoreを表示する場合にも、同じ説明を表示。

## v54 変更
- ABSI表示に「ABSIが高いと何を意味するか」を追記。
- 高いABSIは同じBMI・身長の人と比べて腹囲が相対的に大きいことを表示。
- 高いABSIが高血圧、2型糖尿病、心血管疾患、全死亡リスクの上昇と関連することを説明。
- ABSI単独では病気の診断や個人の発症確率を示せないことを明記。
- z-score表示時にも、高いz-scoreの意味とリスクの見方を追加。

## v54 変更
- 自宅体重グラフに、日常記録の「出来事・体調など」が入力された日の◆マーカーを追加。
- ◆をタップ／クリックすると、その日の出来事をポップアップ表示。
- 体重未測定日でも出来事記録がある場合、選択期間内でマーカーを表示できるよう対応。
- 外来入力に「薬剤経過（グラフ表示用）」を追加。
- 新規投薬は薬剤名＋開始日で登録。開始日は外来受診日を初期値として使用。
- 使用中薬剤には中止日入力＋「中止」ボタンを表示。中止後も履歴を保持。
- 同一薬剤の再開は新しい投薬期間として登録可能。
- 外来体重/HbA1c、GA、eGFRスロープの各画面下に薬剤使用期間タイムラインを表示。
- 使用中薬剤はグラフ右端まで線を伸ばし、▶で継続中を表示。
- 薬剤使用期間データを通常バックアップ・写真を含む完全バックアップの双方に含め、復元にも対応。
